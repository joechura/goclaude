# Not an AI website: the tells, and what to do instead

A site reads as AI/template when every decision is the default. The fix is **specific decisions traceable to a source**: the org's real brand, real media, real words, and named moves borrowed from the inspiration brands.

## Banned defaults → replacements

| Tell | Instead |
|---|---|
| Purple/indigo → blue gradients, neon glows | The org's real brand colors; one accent used sparingly; warm off-white or true black base |
| Inter / system font everywhere, one weight | A display face with character + a readable text face; a real type scale with contrast in size and weight |
| Centered hero: headline, subhead, two pill buttons, blob/gradient behind | Asymmetric hero; real photo/video full-bleed or offset; type overlapping or sized for impact |
| Three equal cards with emoji/line icons | Uneven grid (7/5, 8/4), numbered steps, real photos per item, or a list |
| Glassmorphism, frosted panels, floating cards with big shadows | Flush blocks, hairline rules, solid color fields |
| `rounded-2xl` on everything | A deliberate corner rule (square, or one radius used everywhere) |
| Same fade-up on every element | One signature motion per section (see motion.md) |
| Stock photos of smiling people at laptops | The org's real people (see media.md) |
| Generic copy: "Empower", "Unlock", "Elevate", "Seamless", "Journey", "Transform", "Whether you're X or Y", "In today's world", "We're passionate about" | The org's own words, specific nouns and numbers, short sentences |
| Fake testimonials, round invented stats ("10,000+ happy…") | Real quotes and real numbers with a source URL, or `[TODO]` |
| Footer with 4 identical link columns and social icons only | Footer that does work: donate/contact/address/hours/accessibility statement |
| Every section the same height and padding | Rhythm: vary section density, let one section breathe, let one be dense |

## Required: borrowed moves
For **each** inspiration brand, after actually visiting its site, name **2–3 specific, observable moves** and where they'll be used. A move is concrete enough to build:

- ✅ "Nike: full-bleed product photo with a single huge uppercase word cropped by the viewport edge → used for the hero."
- ✅ "Patagonia: long-form story pages with big pull-quotes and photo captions that credit the photographer → used for Stories."
- ❌ "Nike: bold and athletic." (a vibe, not a move)

Write the source brand next to every design decision in `DESIGN.md`. If a decision has no source (org brand, inspiration move, or accessibility rule), question it.

## Final check before showing the user
Take a screenshot (or render) of the homepage at phone and desktop width and ask: "If I removed the logo, could this be any other org's site?" If yes, it's still generic. Find the defaults and replace them.
